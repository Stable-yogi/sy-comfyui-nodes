# Tool workflows

Small ComfyUI workflows that check or compare things. They use the SY nodes in this pack.

| File | What it does |
|---|---|
| `SY - Setup Doctor v1.json` | Press Run and read the report: your ComfyUI version, node packs that failed to load, start settings and model folders, each problem with one plain fix. It changes nothing. |
| `SY - Checkpoint Contact Sheet v1.json` | The same prompts and the same seed on each checkpoint you list, on one labelled sheet, so you can see which one fits. |

Write the checkpoint names one per line; a part of the file name is enough when it fits only one file.
