# List Stats SY (`SYListStats`)

Source: `nodes/sy_list_stats.py`

**What it does:** Reads a list of numbers and gives the count, sum, average, middle value, smallest and largest.

## Inputs

| Input | Type | Required | What it does | Range / options |
|---|---|---|---|---|
| numbers | STRING | yes | Numbers separated by commas, spaces or new lines. | default '1, 2, 3', multiline |

Outputs: `INT`, `FLOAT`, `FLOAT`, `FLOAT`, `FLOAT`, `FLOAT`, `STRING`
